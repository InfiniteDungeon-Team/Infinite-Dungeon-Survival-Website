# 🎮 Infinite Dungeon Survival — KSU C-Day Graduate Project

**Live Site:**  
https://infinitedungeon-team.github.io/Infinite-Dungeon-Survival-Website/

A twin-stick roguelike survival game built in **Unity** as part of the **Kennesaw State University (KSU) CCSE C-Day Graduate Showcase**.  
This repository hosts the **public project website**, featuring the **Game Design Document (GDD)**, gameplay screenshots, videos, and individual team portfolio pages.
